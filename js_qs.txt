# JavaScript: Core Concepts and Interview Questions

### 1. Data Types in JavaScript
JavaScript has the following data types:
- **Primitive Data Types**:
  - Number
  - String
  - Boolean
  - Undefined
  - Null
  - Symbol
  - BigInt
- **Non-Primitive Data Type**:
  - Object (includes Arrays, Functions, and Objects)

---

### 2. Difference Between `null` and `undefined`
- **`null`**: Represents the intentional absence of any value. It is an object.
- **`undefined`**: Indicates that a variable has been declared but not assigned a value.

Example:
```javascript
let x = null; // explicitly set to "nothing"
let y;       // declared but not initialized
console.log(x); // null
console.log(y); // undefined
```

---

### 3. Difference Between `==` and `===`
- **`==`**: Checks for value equality, performing type coercion if necessary.
- **`===`**: Checks for strict equality, ensuring both value and type are the same.

Example:
```javascript
console.log(5 == '5');  // true
console.log(5 === '5'); // false
```

---

### 4. Difference Between `var`, `let`, and `const`
- **`var`**: Function-scoped, can be redeclared and updated, prone to hoisting issues.
- **`let`**: Block-scoped, can be updated but not redeclared.
- **`const`**: Block-scoped, cannot be updated or redeclared.

Example:
```javascript
var x = 10;
let y = 20;
const z = 30;
```

---

### 5. Synchronous vs Asynchronous in JavaScript
- **Synchronous**: Code is executed sequentially, one task at a time.
- **Asynchronous**: Tasks run independently, allowing non-blocking operations.

---

### 6. Difference Between Callback, Promise, and Async/Await
- **Callback**: A function passed as an argument to another function, executed after a task completes.
- **Promise**: Represents the eventual completion (or failure) of an asynchronous operation.
- **Async/Await**: Simplifies promise handling with `async` functions and `await` keywords.

ans: How the Event Loop Works

   2. Synchronous tasks are added to and executed in the call stack.
   3. When an asynchronous task is encountered (e.g., setTimeout), it is handed over to the Web APIs, and execution continues.

 The event loop:
  1.First checks if the call stack is empty.
  2.Executes all pending microtasks (from the microtask queue).

JavaScript Optional Chaining
ans: JavaScript Optional chaining is a new feature introduced in ES2020 that simplifies the process of accessing properties nested within objects, especially when dealing with potentially null or undefined values. It provides a concise syntax for accessing properties deep within nested objects without encountering errors due to null or undefined values. This helps in writing cleaner and more readable code by reducing the need for explicit null checks and conditionals.

example:
const user = {
    name: 'John',
    address: {
        city: 'New York',
        country: 'USA'
    }
};

// Without optional chaining
if (user && user.address && user.address.city) {
    console.log(user.address.city); // New York
}

// With optional chaining
console.log(user?.address?.city); // New York

### 3. How do you handle API errors in JavaScript?
Use `try...catch` blocks and check HTTP status codes to manage errors gracefully.

Example:
```javascript
try {
    const response = await fetch('https://api.example.com/data');
    if (!response.ok) {
        throw new Error(`Error: ${response.status}`);
    }
    const data = await response.json();
    console.log(data);
} catch (error) {
    console.error(error.message);
}
```

---

### 4. Explain the Concept of CORS (Cross-Origin Resource Sharing)
CORS is a security feature in web browsers that restricts how resources on one domain can be accessed by another domain unless explicitly allowed by the server through HTTP headers.

Example:
A client running on `http://example-client.com` cannot fetch resources from `http://example-server.com` unless the server permits it using CORS headers like:
```http
Access-Control-Allow-Origin: http://example-client.com
```

---

### 5. How to Fetch Data from a REST API Using JavaScript?
You can use `fetch` or libraries like `axios` to make API calls.

**Using Fetch:**
```javascript
fetch('https://api.example.com/data')
    .then(response => response.json())
    .then(data => console.log(data))
    .catch(error => console.error('Error:', error));
```

**Using Axios:**
```javascript
import axios from 'axios';

axios.get('https://api.example.com/data')
    .then(response => console.log(response.data))
    .catch(error => console.error('Error:', error));
```

### 6. What are HTTP Methods Commonly Used in REST APIs?
- **GET**: Retrieve data from the server.
- **POST**: Send data to the server to create a resource.
- **PUT**: Update an existing resource entirely.
- **PATCH**: Update part of an existing resource.
- **DELETE**: Remove a resource from the server.

---

### 7. What is the Role of Headers in API Requests?
Headers provide additional information about the request or response. Examples include:
- **Content-Type**: Specifies the type of data being sent (e.g., `application/json`).
- **Authorization**: Contains credentials for authentication (e.g., Bearer tokens).
- **Accept**: Specifies the type of data expected in the response.

---

### 8. What is API Throttling?
API throttling limits the number of API requests a client can make in a given time period. This helps prevent abuse and ensures fair usage for all clients.

---

### 9. What is a CRUD Operation?
CRUD stands for Create, Read, Update, and Delete. These are the four basic operations for managing resources in a RESTful API.

| Operation | HTTP Method |
|-----------|-------------|
| Create    | POST        |
| Read      | GET         |
| Update    | PUT/PATCH   |
| Delete    | DELETE      |

---

### 10. What is the Difference Between Synchronous and Asynchronous APIs?
- **Synchronous APIs**: The client waits for the server to respond before continuing. 
- **Asynchronous APIs**: The client does not wait for the server response and can execute other tasks. Responses are handled via callbacks, promises, or `async/await`.
