what is life cycles in the functional components.
ans: In functional components, we can perform the life cycles using hooks. The most commonly used hooks are useEffect and useState.

how can we perform the life cycles in functional components.
ans: Here are concise definitions for lifecycle methods in functional components using React Hooks:

1. **ComponentDidMount (Mounting Phase)**  
   Runs once when the component is mounted (added to the DOM). In functional components, this is achieved using `useEffect` with an empty dependency array (`[]`).

   ```javascript
   useEffect(() => {
       // Code to run on mount
   }, []);
   ```

2. **ComponentDidUpdate (Updating Phase)**  
   Runs after the component updates due to changes in props or state. This is achieved using `useEffect` with specific dependencies in the dependency array.

   ```javascript
   useEffect(() => {
       // Code to run when 'dependency' changes
   }, [dependency]);
   ```

3. **ComponentWillUnmount (Unmounting Phase)**  
   Runs when the component is about to unmount (removed from the DOM). In functional components, this is handled by returning a cleanup function from `useEffect`.

   ```javascript
   useEffect(() => {
       // Code to run on mount
       return () => {
           // Cleanup code to run on unmount
       };
   }, []);
   ```

These lifecycle equivalents in functional components are implemented using the `useEffect` hook, making it a versatile tool for handling side effects and lifecycle events.
